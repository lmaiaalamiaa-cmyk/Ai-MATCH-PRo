# AI MATCH PRO — النسخة الأولية

هذا مشروع Android أولي باستخدام Kotlin وJetpack Compose.

## البناء على CodeMagic
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. اربط المستودع في CodeMagic.
3. اختر Workflow باسم `android-debug`.
4. شغّل البناء وحمّل ملف APK من Artifacts.

## مهم
- هذه النسخة تعرض واجهة تجريبية فقط.
- أسماء المباريات والنتائج أمثلة وليست بيانات مباشرة.
- لم تتم إضافة API key أو ربط مزود بيانات بعد.
- لا تضع مفاتيح API السرية داخل تطبيق Android؛ يجب حفظها في خادم خلفي أو متغيرات بيئة آمنة.
- التوقعات احتمالية وليست مضمونة.
